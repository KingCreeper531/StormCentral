# Doto

The dot-matrix display font of the "Dot Matrix" themes (`"font": "dot"` in a theme add-on) and the
Android Dot widget (`android/app/src/main/res/font/doto_round.ttf`, a static instance at weight 800
with round dots).

- Source: [@fontsource-variable/doto](https://www.npmjs.com/package/@fontsource-variable/doto) 5.3.0,
  latin subset, wght and ROND axes. Upstream: https://github.com/oliverlalan/Doto
